About this admin page & API

Same Firebase project as JewelHeart Admin apps (iOS/Android). REST API: https://api.karmadots.org/jewelheart/. Specs, migrations, and native shells live in JewelHeartAdminFunction (OpenAPI openapi/jewelheart.yaml). Mobile schedule UI is SDUI on the same API (retreat.schedule, retreat.schedule.day; server router private-server/src/jewelheart/sduiScreens.js in buddhist-stone-ios-app). Postgres ACL: jewelheart_admins / jewelheart_retreat_admins. Sign in with Firebase (Google, email, anonymous) or Keycloak (same realm as the KarmaDots apps). Unauthorized domain → Firebase Authentication → Authorized domains.

Bulk retreat data: The July 20–25, 2026 volunteer grid (jobs, slots, tasks) from the v2 Excel pack is seeded with scripts/seed_summer_retreat_july_2026_from_xlsx.py in that repo (run against the same DATABASE_URL as private-server; see script docstring). This page is for sign-in and ongoing CRUD after rows exist.

Sign in

Phone sign-in uses Firebase SMS (not Twilio). Enable Phone in Firebase Console → Authentication → Sign-in method, and add this site to Authorized domains.
