Admin functions v0.1.
	•	General structure
	•	Job: main assignable unit of work
	•	Example: Full clean main men’s room
	•	Slot: day and time for a job
	•	Example: Day 2, lunchtime
	•	Possible times: early, lunchtime, dinnertime, anytime
	•	Task: a job in a slot
	•	Example: Full clean main men’s room, Day 2, lunchtime
	•	Assignment: a volunteer assigned to a task (job, slot)
	•	Example: Dan Rosen, assigned to full clean main men’s room, day 2, lunchtime
	•	Unassigned (or underassigned) task: task with no assignment, or not enough volunteers
	•	Schedule, all the tasks, some with assignments.
	•	Job  management
	•	Add/delete/edit/list jobs: title, subjobs (purely descriptive, no structure), # volunteers, estimated time (for all assigned volunteers, working together)
	•	Examples

	•	Mop toilet stall floor
	•	Replenish TP in stall
	•	Replenish paper towels on counter
	•	Replenish paper towels in dispenser
	•	Etc
